# RTT 교차 재현 차이 기록

공식 2022 Deluxe 영문 룰북을 우선 적용한다. RTT와 Python 엔진의 의미 상태가 다른 경우 원본 입력 번호, 규칙 조항, 관측값, 판정을 여기에 기록한다.

## 판정이 필요한 규칙·기록 차이

| 첫 입력 | 필드 | RTT 관측 | Python 판정 | 근거 |
| ---: | --- | --- | --- | --- |
| 168 | `spaces.ARABIA.control` | AP 지배 유지 | CP 지배로 전환 | 2022 Deluxe 영문 룰북 14.3.6은 보급이 끊긴 지배 공간에 아라비아를 명시적으로 포함한다. RTT `rules.js`의 `goto_attrition_phase`는 아라비아를 건너뛴다. |
| 1446 | `result` | CP 승리 (`cp`) | AP 승리 | 같은 RTT 상태의 `victory`와 로그에는 “Central Powers resigned.”라고 기록된다. RTT `resign` 함수에 역할 문자열 `Central Powers`를 전달하면, 진영 코드 `cp`를 기대하는 `other_faction`이 `cp`를 반환한다. Python의 `RESIGN`은 항복한 CP의 상대인 AP를 승자로 둔다. |

`ReplayReport.adjudicated_differences`가 두 차이를 원본 입력 번호·값·근거와 함께 반환한다. 대조 시 이 두 조건만 명시적으로 판정하고 나머지 첫 차이는 실패로 보고한다.

## 재현 어댑터의 입력 보정

초기 이탈리아 동형 군단 여섯 개는 배치 수가 같지만 RTT와 Python의 개별 ID가 다르다. 재현용 초기 상태에서 RTT ID에 맞춰 배치한다. RTT와 Python의 카드 난수 알고리즘도 달라 초기 손패·덱 순서와 턴별 실제 보충 결과를 재현용 초기 상태에 기록한다. 이 기록은 카드 다중집합이 유지될 때만 적용되며 일반 게임 초기화의 난수 처리는 바꾸지 않는다.

RTT 미세 입력 중 되돌리기는 정제 단계에서 제거한다. 이 문서의 판정 차이와 별개로, 대조기는 행동 단계 또는 게임 종료 상태에서 유닛, 지배권, 참호, 요새, 카드 구역, 전쟁 상태, 전쟁 참여 수준, VP, 승자를 비교한다.
