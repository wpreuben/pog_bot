# 2022 Deluxe 룰북과 RTT 구현 대조

영문 2022 Deluxe 룰북을 우선한다. RTT `rules.js`는 카드·지도 자료와 구현 참고 자료이며, 확인한 차이를 아래에 기록한다.

| 규칙 | 확인 내용 | 엔진 판정 |
| --- | --- | --- |
| 6.0 E.1–E.4 | 룰북은 VP 변경 → 자동 승리 → 휴전 → 전쟁 헌신도 변경 순서다. RTT는 헌신도 변경을 자동 승리보다 먼저 실행한다. | 룰북 순서로 처리한다. E.2에서 끝나면 새 카드를 덱에 넣지 않는다. |
| 5.7.4.8–9 | Historical 최종 VP 조정은 휴전·20턴 종료에만 적용한다. | E.2 자동 승리에는 적용하지 않는다. |
| 5.7.2, 16.5 | Historical에서는 평화 조건 제안을 사용할 수 없다. | 제안 행동을 제공하지 않는다. |
| 9.5.2.4.1, 9.5.3.4 | Salonika 이후 MEF 상륙은 금지되지만, 9.5.3.4의 통상 영국 증원 배치는 허용된다. | MEF 특수 상륙 공간을 닫고 영국 본토 배치는 허용한다. |

전투 결과표(CRT)는 제공된 PDF 본문에 표 전체가 없어 RTT의 수치를 자료 파일로 정규화했다. 인쇄된 보조표 원본을 확보하면 칸별 재대조가 필요하다.
